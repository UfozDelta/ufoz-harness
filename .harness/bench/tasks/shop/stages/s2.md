# Stage 2: Product catalog

Read `../spec.md` first (Goal, Starting point, Decisions — including the fixed product table —
apply to every stage below).

## What exists already
`/` — landing page with `data-testid="site-nav"`, `"hero"`, `"cta-shop"`, `"features"`,
`"site-footer"`, and links to `/products`. Keep it working exactly as stage 1 left it (do not edit
`app/page.tsx`'s content/testids).

## Goal
A DB-backed product catalog: seed the fixed 6 products from `../spec.md` into SQLite on first use,
expose them over an API, and render a catalog page + a detail page.

## DB
`lib/db.ts`: open `node:sqlite` `DatabaseSync` at `process.env.SHOP_DB_PATH || "data/shop.db"`,
creating the parent directory if missing. Create table `products(id INTEGER PRIMARY KEY, slug TEXT
UNIQUE, name TEXT, price_cents INTEGER, stock INTEGER, description TEXT)` if missing, and if it is
empty, insert the 6 rows from `../spec.md` in id order. Export a helper to get the singleton DB
instance, reused by every route/page in every later stage.

## API (JSON everywhere)
- `GET /api/products` → 200 `{"products": [{"id","slug","name","priceCents","stock","description"}...]}`,
  ordered by `id` ascending (all 6).
- `GET /api/products/{slug}` → 200 the single product object (same shape), or 404
  `{"error": "..."}` when no product has that slug.

Both routes export `dynamic = "force-dynamic"`.

## Pages
- `/products` — server-rendered catalog grid from the DB. `data-testid="product-grid"` wrapping one
  `data-testid="product-card"` per product (6 total), each linking to `/products/{slug}`. Each card
  contains `data-testid="product-name"` (the name) and `data-testid="product-price"` (price
  formatted as `$X.XX`, e.g. `$29.99` for 2999 cents).
- `/products/{slug}` — server-rendered detail page. On a known slug: `data-testid="product-detail"`
  wrapping `data-testid="product-name"`, `data-testid="product-price"` (`$X.XX`),
  `data-testid="product-stock"` (containing the integer stock count as text), and
  `data-testid="product-description"`. On an unknown slug: call Next's `notFound()` so the response
  is HTTP 404, and the rendered page contains `data-testid="not-found"`.
- Both pages export `dynamic = "force-dynamic"`.

## Design
Same visual system as stage 1 (reuse `app/globals.css`, same nav/footer). Responsive grid down to
375px (cards stack to 1 column). Apply the Design decision from `../spec.md`.

## Build rules
- `npm run build` succeeds with zero type errors. No new dependencies.
- Do not modify the landing page's testids or the fixed product table.
