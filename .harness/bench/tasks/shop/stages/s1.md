# Stage 1: Landing page

Read `../spec.md` first (Goal, Starting point, Decisions apply to every stage below).

## What exists already
Nothing shop-specific yet — only the bare Next.js starting point.

## Goal
A single marketing landing page at `/` for the "Nimbus Goods" dropshipping store. No database, no
API routes in this stage.

## Page: `/`
Replace the placeholder `app/page.tsx`. Server component, static content (no DB, no
`dynamic = "force-dynamic"` needed since nothing here touches the DB). Must include, each wrapped in
an element carrying the given `data-testid`:

- `data-testid="site-nav"` — a nav bar containing the text `Nimbus Goods` and a link
  `<a href="/products">Shop</a>` (the target page doesn't exist until stage 2 — that's fine, don't
  build it here).
- `data-testid="hero"` — a hero section containing an `<h1>` with the text `Nimbus Goods` and a short
  tagline sentence (your wording) in the same section.
- `data-testid="cta-shop"` — a call-to-action `<a href="/products">` (button-styled link) with
  visible text containing the word `Shop` (case-insensitive).
- `data-testid="features"` — a section listing at least 3 short feature/benefit bullets (your
  wording, e.g. free shipping, fast dispatch, easy returns).
- `data-testid="site-footer"` — a footer containing the text `Nimbus Goods`.

## Design
Apply `../spec.md`'s Design decision (emil-design-eng + apple-design skills). Add
`<meta name="viewport" content="width=device-width, initial-scale=1">` in `app/layout.tsx` if not
already present. Responsive down to 375px: nav, hero, and features must not overflow horizontally at
that width. Respect `prefers-reduced-motion` for any transition/animation you add — none is required.

## Build rules
- `npm run build` succeeds with zero type errors.
- No new dependencies. Plain CSS only (`app/globals.css` and/or CSS modules).
- Do not create `/products` or any API route in this stage — later stages own them.
