GOAL: Add the cart page and the checkout stub page (shipping form + "Place Order" that fires the
conversion event with the UTM params attached).

CONTEXT: Available already — `lib/products.ts` (`getProduct`), `lib/cart-context.tsx`
(`useCart` -> `lines`, `removeItem`, `clearCart`, `itemCount`, `total`), `lib/analytics.ts`
(`trackPlaceOrder`), `lib/utm.ts` (`getUtmParams`). There is no backend and no payment processor:
checkout is a stub.

FILES (create; touch nothing else):
- `storefront/app/cart/page.tsx`
- `storefront/app/checkout/page.tsx`

REQUIREMENTS:
- Both files start with `"use client";` (they read cart state).
- `cart/page.tsx`: lists each cart line — product name (via `getProduct(line.slug)`), quantity, line
  price — plus a "Remove" button calling `removeItem(line.slug)`, the cart `total` formatted as
  `$<total>` with 2 decimals, a `<Link href="/checkout" className="cta">Checkout</Link>`, and an
  empty state ("Your cart is empty" + a link back to `/`) when `lines.length === 0`. Guard against
  `getProduct` returning `undefined` (skip that line).
- `checkout/page.tsx`: a controlled form (`useState`) with required inputs `fullName`, `email`,
  `address`, `city`, `postalCode`, `country`, and a `<button type="submit" className="cta">Place Order</button>`.
  `onSubmit` calls `event.preventDefault()`, then
  `trackPlaceOrder({ value: total, items: lines.map((l) => l.slug) })`, then `clearCart()`, then sets
  a `placed` state that swaps the form for a "Thank you! Your order is confirmed." message.
  Render the order total. Disable/skip submission when the cart is empty (show "Your cart is empty").
- `trackPlaceOrder` already merges `getUtmParams()` into the event payload — do NOT re-implement UTM
  reading here, just import nothing extra for it.
- No `fetch`, no API route, no payment SDK, no card fields.

CONSTRAINTS: no new dependencies; no edits to files from earlier tasks; touch only the listed files;
never run git commands that change state.

ACCEPTANCE (run from the project root; must print `CHECKOUT OK` and exit 0):
`python .harness/plans/bench-plan/checks/check_t7.py`
