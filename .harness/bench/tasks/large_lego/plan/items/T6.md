GOAL: Add the product detail page (PDP) at `/product/[slug]` and the client-side Add to Cart button
that fires the ads AddToCart event.

CONTEXT: Available already — `lib/products.ts` (`products`, `getProduct`, `Product`),
`lib/cart-context.tsx` (`useCart`), `lib/analytics.ts` (`trackAddToCart`). The layout already wraps
pages in `CartProvider`.

FILES (create; touch nothing else):
- `storefront/app/product/[slug]/page.tsx`
- `storefront/components/AddToCartButton.tsx`

REQUIREMENTS:
- `page.tsx`: server component. Signature
  `export default function ProductPage({ params }: { params: { slug: string } })`.
  Looks the product up with `getProduct(params.slug)`; when undefined, calls `notFound()` from
  `next/navigation`. Renders the `<img src={product.image} ... />` (plain `<img>`, not `next/image`),
  `<h1>` name, price as `$<price>` with 2 decimals, the description, a `<Link href="/">` back link,
  and `<AddToCartButton product={product} />`.
- Also export `export function generateStaticParams()` returning
  `products.map((p) => ({ slug: p.slug }))`.
- `AddToCartButton.tsx`: starts with `"use client";`. Props `{ product: Product }`. Renders a
  `<button className="cta">Add to Cart</button>` whose `onClick` calls `addItem(product)` from
  `useCart()` and then `trackAddToCart(product)`. After a click, show the text "Added" (local
  `useState`) — no navigation, no alert.

a global 404 page; touch only the listed files; never run git commands that change state.
