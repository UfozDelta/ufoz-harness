GOAL: Add the ads instrumentation: Meta Pixel, TikTok Pixel and Google gtag snippets, the event
helper functions, and first-load UTM capture.

CONTEXT: Traffic comes from Meta/TikTok/Google ads. The three env vars already exist in
`storefront/.env.local`: `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_TIKTOK_PIXEL_ID`,
`NEXT_PUBLIC_GA_MEASUREMENT_ID`. `storefront/lib/products.ts` exports the `Product` type.
The layout mounts `AnalyticsScripts` in a later task — do not edit any page here.

FILES (create; touch nothing else):
- `storefront/lib/utm.ts`
- `storefront/lib/analytics.ts`
- `storefront/components/AnalyticsScripts.tsx`

REQUIREMENTS:
- `utm.ts`:
  - `export type UtmParams = Record<string, string>;`
  - `export const UTM_STORAGE_KEY = "utm_params";`
  - `export function captureUtmParams(): UtmParams` — returns `{}` when `typeof window === "undefined"`.
    Reads `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` from
    `new URLSearchParams(window.location.search)`. If `sessionStorage` already holds
    `UTM_STORAGE_KEY`, return the stored value unchanged (first landing URL wins). Otherwise, when at
    least one param is present, `sessionStorage.setItem(UTM_STORAGE_KEY, JSON.stringify(found))` and
    return it. Wrap storage access in try/catch and fall back to `{}`.
  - `export function getUtmParams(): UtmParams` — parses the stored JSON, `{}` on miss or error.
- `analytics.ts`:
  - Declare the globals, e.g. `declare global { interface Window { fbq?: (...args: any[]) => void;
    ttq?: { track: (...args: any[]) => void; page: () => void }; gtag?: (...args: any[]) => void } }`.
  - `export function trackPageView(): void` — calls `window.fbq?.("track", "PageView")`,
    `window.ttq?.page?.()`, and `window.gtag?.("event", "page_view")`.
  - `export function trackAddToCart(product: Product): void` — Meta `fbq("track","AddToCart",{content_ids:[slug],
    content_name:name, value:price, currency:"USD"})`, TikTok `ttq.track("AddToCart", {...})`,
    gtag `gtag("event","add_to_cart",{...})`.
  - `export function trackPlaceOrder(payload: { value: number; items: string[] }): void` — Meta
    `fbq("track","Purchase", {...})`, TikTok `ttq.track("PlaceAnOrder", {...})`, gtag
    `gtag("event","purchase", {...})`; each payload spreads `getUtmParams()` so the UTM values ride along.
  - Every call must be safe when the global is undefined (optional chaining or a `typeof window` guard).
- `AnalyticsScripts.tsx`: starts with `"use client";`, default-exports `AnalyticsScripts`, imports
  `Script from "next/script"`. Renders the three standard inline snippets with
  `strategy="afterInteractive"`, reading the IDs from `process.env.NEXT_PUBLIC_META_PIXEL_ID`,
  `process.env.NEXT_PUBLIC_TIKTOK_PIXEL_ID`, `process.env.NEXT_PUBLIC_GA_MEASUREMENT_ID`
  (each snippet skipped — render `null` for it — when its ID is missing). The Meta snippet defines
  `fbq`, the TikTok snippet defines `ttq`, the Google snippet loads
  `https://www.googletagmanager.com/gtag/js?id=<id>` and defines `gtag`. Inline scripts use
  `dangerouslySetInnerHTML={{ __html: "..." }}`. A `useEffect(() => { captureUtmParams(); trackPageView(); }, [])`
  runs on mount.

CONSTRAINTS: no analytics npm packages — raw snippets only; no `<img>` noscript pixel needed; no edits
to pages, layout or products; no new dependencies; never run git commands that change state.
