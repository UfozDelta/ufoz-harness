# Spec (multi-file-feature): sorted and paged inventory listing

The inventory package can store items, but the only listing returns them in insertion order. We need to list items sorted by `sku`, `name`, `qty` or `price`, optionally reversed, and split into pages. Ties are broken by sku ascending, and names compare case-insensitively. Sorting happens before paging, and `reverse` flips the final order, tie-breaks included. Page numbers start at 1, a page past the end is an empty list, and `count_pages(inv, per_page)` returns how many pages there are. An unknown sort key, a page or per_page below 1, or a page given without per_page raises ValueError, while per_page alone returns the first page and calling `list_items(inv)` with no other arguments keeps returning insertion order. Interface: `Inventory.items(sort=None, reverse=False)` in `inventory/store.py` does the sorting and raises on an unknown key; `inventory.api.list_items(inv, sort=None, reverse=False, page=None, per_page=None)` delegates to it and pages the result; `count_pages(inv, per_page)` lives in `inventory/api.py`.
